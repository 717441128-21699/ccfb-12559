# 热像仪火场搜索训练仿真

面向消防新队员的长波红外（LWIR, 8–14µm）热像仪训练系统。在三维着火房间中模拟
真实热物理与红外成像，训练队员在浓烟、水雾、反射假热点干扰下的搜索与判读能力。
渲染管线基于 **WebGL2**，其余仿真逻辑全部为 **TypeScript**。

## 运行

```bash
npm install
npm run dev        # 开发服务器
npm run build      # 生产构建
npm run preview    # 预览构建产物

# 测试
npx tsx test/smoke.ts   # 物理层 22 项冒烟测试
node test/e2e.mjs       # 无头浏览器 23 项端到端测试（需先启动 dev server）
```

## 物理与红外模型

- **火源**：t² 火（slow/medium/fast 增长系数），Hesketh 火焰高度，闪烁温度
- **烟气**：双区层模型，界面高度随时间下压，上层能量平衡（kW→J 单位一致）
- **传热**：物体集总热容（对流 + 火源点源辐射 + 热烟气辐射，含视线遮挡）；
  墙面在 **GPU 浮点纹理上做显式热扩散**（六壳面 ping-pong，10Hz）
- **红外辐射**：10µm 单色普朗克公式（GLSL 与 TS 同系数，可逆用于十字线读数）
- **LWIR 介质**：薄烟消光取可见光的 0.25（可穿透）；水雾因水滴粒径与波长相当而强遮挡
- **假热点**：玻璃/金属低发射率 + Schlick 菲涅耳，反射环境立方体贴图中的热区与火光
- **调色板**：铁红 ironbow、白热 white-hot，叠加传感器噪声与屏幕十字线

## 两个关键验收点的实现

1. **AGC 单帧切换**（`src/render/rangeController.ts`）
   - 自动模式逐帧用画面 min/max 平滑自适应，火焰进视野后上限被拉高、常温区压黑；
   - `lock()` 当帧冻结量程，锁定后 `update()` 直接返回冻结值、无插值，
     同一物体亮度不再随火焰进出视野变化；切回自动立即恢复自适应。

2. **30fps 保障**（`src/app/engine.ts`）
   - 物理固定 10Hz 步长与渲染解耦；连续低帧时自动以 10% 步进下调渲染分辨率（最低 60%），
     帧率恢复后回升；反射立方体贴图可按帧间隔刷新。

## 回放确定性

物理 10Hz 固定步长、无随机数（着色器噪声为确定性 hash），两次演化逐位一致。
录制时每 5s 存一个含墙面热纹理的完整关键帧、10Hz 存轻量相机轨迹；
拖进度条时定位最近关键帧恢复后最多快进 50 步，保证跳转快速且结果可复现。

## 兼容性说明

浮点纹理统一采用 **RGBA16F/R16F**（半浮点）而非 R32F：部分 ANGLE/SwiftShader
实现中 32 位浮点纹理作为着色器采样源存在缺陷。int 型 uniform 一律使用 `uniform1i`，
采样器数组在片元着色器中以常量索引 if 链访问（GLSL ES 3.00 动态采样器索引为可选特性）。
